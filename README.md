# GramSetu

AI-Enabled Digital Governance Platform for Gram Panchayat Citizen Services and Grievance Management.

## Overview

GramSetu is an academic project prototype designed to simplify citizen access to Gram Panchayat services and improve grievance management.

## Main Modules

- Citizen Portal
- Panchayat Official Dashboard
- Field Worker Dashboard
- System Administrator Portal

## Planned Features

- Citizen registration and authentication
- Online service applications
- Document upload and verification
- Application tracking
- Grievance submission and tracking
- Field worker task assignment
- GIS-based grievance visualization
- AI-assisted grievance classification
- Notifications and analytics

## Planned Technology Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- PostGIS
- Python
- FastAPI
- Leaflet

## Project Status

Initial development setup.

Features will be marked as complete after implementation and testing.
